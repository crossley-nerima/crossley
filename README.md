# X-III（クロスリー）ホームページ デザイン案

練馬駅のバー「X-III（クロスリー）」のホームページの、デザイン案 11 パターンです（11 案目は、機能をひととおり入れた参考用の見本）。

- 公開アドレス: https://crossley-nerima.github.io/crossley/ （開くと案01が表示されます。上の帯の「11案を切り替え」で切り替えられます）
- 提案中なので、検索エンジンには出ない設定（noindex）にしています。

## 中身

| フォルダ・ファイル | 内容 |
|---|---|
| `site.json` | 店の情報（店名・住所・営業時間・料金・メニューなど）。**情報はここだけに書く** |
| `patterns.json` | 10 案の名前・説明・構成 |
| `src/<案>/` | 各案のひな形（HTML・CSS・JavaScript） |
| `src/_common/` | 提案のときだけ使う部品（案の切り替えの帯・「仮」の札） |
| `src/_parts/` | 全案に差し込む部品。`route-map.svg`（道順の図）、`parts.css`（道順の図・入口のようす・お知らせの見た目）、`notices.js`（お知らせと「いま営業中か」の計算） |
| `docs/` | 書き出したサイト（GitHub Pages はここを公開する） |
| `build.py` | `site.json` をひな形に差し込んで `docs/` に書き出す |
| `tools/prepare_photos.py` | 写真を Web 用に縮め、撮影情報を消し、テレビの画面をぼかす。チラシからロゴを抜き出し、下の「CROSS THREE」を「CROSSLEY」に描き直す |
| `tools/fonts/` | ロゴの「CROSSLEY」に使う書体 Barlow（SIL Open Font License。`OFL.txt`） |
| `tools/shoot.py` | 書き出したページを画面なしの Edge で撮って、崩れを確かめる |
| `tools/get_sample_photos.py` | 案11で使う見本の写真（ウィキメディア・コモンズの、誰でも使ってよい条件の写真）を取ってくる。作者と条件は `site.json` の `sample_photos` |
| `signs.json` | 1階入口の看板（光る置き看板）のポスターの提案（10案）の中身（スタンド・載せること・説明・予算・印刷の頼み方・注意・出どころ） |
| `src/signs/` | 看板のポスターの提案のページのひな形（提案のときだけ `docs/signs/` に書き出す。本番では消える） |
| `tools/make_sign_images.py` | 看板のポスター10案（置いたイメージ・ポスターのデザイン・一覧用）と、スタンドの大きさの図、まとめて保存する ZIP を作る |
| `tools/make_route_map.py` | 練馬駅から店までの道順の図を、OpenStreetMap の地図データから作る（歩く道・番号の位置はこの中に書く） |

## 道順を直すとき

1. 手順の文は `site.json` の `route`。図の番号（1〜4）と順番を合わせる。
2. 通る場所や番号の位置を変えるときは `tools/make_route_map.py` の `VIA`（通る場所。あいだは道に沿って自動でつなぐ）・`STEPS` を直し、`python -I -X utf8 tools/make_route_map.py` で図を作り直す。
3. 図の色は各案の `style.css` の `.route-map { --rm-… }` で変える。

## お知らせ（臨時休業・臨時営業）を出すとき

1. `site.json` の `notices` に1行足す。
   - 臨時休業: `{"from": "2026-11-03", "type": "closed", "text": "店主都合により、臨時休業いたします。"}`
   - 何日も続く休み: `{"from": "2026-12-30", "until": "2027-01-03", "type": "closed", "text": "年末年始のお休みをいただきます。"}`
   - 臨時営業: `{"from": "2026-11-08", "type": "open", "text": "日曜日ですが、特別に営業します。"}`（時間が違えば `"open": "20:00", "close": "05:00"` を足す）
   - そのほか: `"type": "info"`
2. 書き出して送る（全 10 案のトップに出る）。
3. 日付が過ぎたお知らせは、ページを開いた人の画面で自動で隠れる（翌朝 7 時で切り替わる）。`site.json` から消すのは、ときどきでよい。
4. 臨時休業・臨時営業は、案09の「営業中」の表示と、検索エンジン向けの店舗情報（特別な営業時間）にも反映される。
   Google マップの「特別営業時間」も同じ内容に直しておくと、地図の表示とずれない。
5. `"sample": true` は提案用の見本。日付が過ぎても消えず、提案中は「見本」の説明が付く。本番の書き出し（`proposal: false`）では、残っていると止まる。

## 店の情報を直すとき

1. `site.json` を直す。まだ決まっていない値は `{"v": "値", "tbd": true}` の形で、ページに「仮」の札が付く。決まったら `tbd` を消す。
2. `python -I -X utf8 build.py` で書き出す（全 10 案に反映される）。

## 写真を差し替えるとき

`python -I -X utf8 tools/prepare_photos.py <写真のフォルダ> docs/assets/img`

## 本番にするとき

1. 案を 1 つに決め、`site.json` の `"proposal"` を `false` にする（検索に出る設定になり、案の切り替えの帯と「仮」の札が消える）。
   まだ「仮」の値が残っていると、書き出しが止まる。
2. 独自ドメインを使うなら `base_url` を直す（共有したときの画像・検索エンジン向けの店舗情報に使う）。

## 案11（機能モリモリ）について

- バーのホームページでよく使われる機能（18個）をひととおり入れた、参考用の見本。提案中は各機能に「機能○」の説明の札が付く（本番では出ない）。
- バーテンダーやカクテルの写真は見本（フリー素材）。お店の写真が届いたら差し替える。
- 機能の名前と説明は `patterns.json` の案11の `features`。
- LINE 公式アカウント: お店がアカウントを作ったら、`site.json` の `line_oa` に ID（@ から始まる）を書いて `tbd` を消す。
  友だち追加のボタンと、予約リクエストの「LINEで送る」（文面を入れた状態で LINE のトークを開く）が動くようになる。
  QR コードは、お店の管理画面から出せる画像を `docs/assets/img/line-qr.png` に置き、`site.json` に `"line_qr": "line-qr.png"` と書く。
- 「お店の方へ：教えてください」（案11のいちばん下・提案中だけ）: お店の人がスマホで答えを書き、「LINEで送る」で回答をまとめた文面を送ってくれる。
  質問は `site.json` の `shop_questions`。答えが届いたら、その内容を `site.json` に入れて、質問を消す。

## 看板のポスターの提案（1階入口・10案）について

- 看板の本体は、お店が決めた光る置き看板（モノタロウの LEDパネルA型スタンド 片面・A1。注文コード 05348546）。
  その中に差し込む A1（594 × 841mm）のポスターを作っている。
- 最初の10案から、案06「3枚の写真で見せる」に決まった（2026-10-30）。お店の意見（「タバコ吸えます」を目立たせる・「2026年7月 NEW OPEN」を押し出す・
  焼酎とテキーラは載せない・写真の上の説明は入れない）を入れて、仕上げの10案にした（前の10案は消した）。意見と直したことは `signs.json` の `changes`。
  どの案も、BAR・ロゴ・3F・NEW OPEN・タバコ・テーブルチャージ・値段の目安（ビール・ウイスキー・カクテル・フード・ダーツ）・写真3枚・営業時間・Instagram を載せている。
- ページは `docs/signs/index.html`。どの案の「11案を切り替え」からも、いちばん下の「ほかの提案」から開ける。
- ページの中身: まずはここだけ（ご意見と直したこと）／決まっているスタンド／ポスターに載せること（値段の「仮」の一覧）／10案を見比べる（かんたん診断・一覧・表）／
  くわしい説明（置いたイメージとポスター・よいところ・気をつけるところ）／選び方／予算（5万円まで）／印刷の頼み方／これからの流れ／
  気になる案を送る（お店の人が印を付け、決まった値段も書いて LINE で送る）／よくある質問／決まり・注意／言葉の説明／出どころ。
  「印刷・PDFで保存」で紙にもできる（操作する部分は印刷されない）。
- 値段は `site.json` から入る（`charge` と `menu` の値段・`food`・`darts_price`。計算は `build.py` の `sign_prices`）。
  値段が決まったら `site.json` を直し、`python -I -X utf8 tools/make_sign_images.py` で画像を作り直してから `build.py` で書き出す。
  番号を渡すとその案だけ作り直す（例 `01,05`。`00` は今のようす、`stand` はスタンドの大きさ）。番号なしだと、古い画像を消して全部作り直す。
- 画像はイラスト。建物はストリートビュー（2024年11月）をもとに描き起こした（Google の画像は加工して公開できないため）。ポスターの写真はお店の写真（ホームページの案と同じ）。
- 金額は 2026年10月に販売ページで確かめた値。出どころは `signs.json` の `sources`。
