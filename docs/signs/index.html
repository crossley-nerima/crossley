PROBLEMいま困っていること

  1. 3階にバーがあると気づけない外から見えるのは1階と2階のお店ばかりで、3階の窓は電線にも隠れます。前を通っても、上にバーがあるとわかりません。
  2. 目の前に来ても、入口がわからない入口のガラス扉は、隣のお店の木の扉と並んでいます。今あるのは、案内板の3階の小さなプレートだけです。
  3. 中が見えないので、上がりにくい初めての人には、3階にどんなお店があるのか、いくらかかるのかがわかりません。

GOAL看板で解決したいこと

10案それぞれが、この3つにどれだけ効くかを ●（3段階）で示しています。

  • 気づく通りや交差点の向こうから「ここにバーがある」と気づける
  • 入口がわかる「3階」「このドアからエレベーターで」が、目の前ですぐわかる
  • 上がりたくなるお店の雰囲気・値段・営業中かがわかり、初めてでも上がってみたくなる

看板と一緒にやると、さらに迷わない

入口のガラス扉に「3F BAR XⅢ」の文字（カッティングシート）を貼ると、隣のお店のドアと迷わなくなります。施工込みで5万円前後が平均です（扉はビルの共用部分なので、管理会社の承諾が要ります）。

出どころ：看板制作の費用相場・カッティングシート（アイミツ）

RULES置くときの決まり・注意

  1. 置くのは、ビルの敷地の中だけ歩道は道路なので、看板を置くと道路法の違反になります。入口の前の段の上など、ビルの敷地の中に置き、通る人のじゃまにならないようにします。
  2. ビルの管理会社・オーナーの承諾入口のまわりはビルの共用部分です。置く前に、場所と大きさを伝えて承諾をもらいます。
  3. 光る看板には電源が要る屋外用（防水）のコンセントが必要です。どこから電気をとるか、管理会社と相談します。
  4. 倒れない・閉店したらしまう風で倒れないよう台に重りを入れます。営業中だけ出せば、「出ている＝営業中」の合図にもなります。
  5. 東京都の屋外広告物条例置き看板も、この条例の対象です。お店の看板（自家用）は、表示面積の合計が基準（多くの地域で10㎡、地域によって5㎡）以下なら許可は要りませんが、決まりは守る必要があります。わからないことは練馬区に相談できます。

QUOTE見積もりを取るときに伝えること

  • 置く場所の写真と寸法（入口の前のすき間の幅・奥行き）
  • 片面か両面か（4面か）、光らせるか
  • 屋外に置くこと（雨・風）と、電源の場所
  • 入れたい文字（BAR、XⅢ クロスリー、3F、営業時間）と、ロゴのデータ
  • 2〜3社から見積もりを取り、税込か税別か、運搬・設置が入っているかを確かめる
